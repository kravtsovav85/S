Политика обработки персональных данных

Контакт по вопросам обработки персональных данных и отзыва согласия: i@avkravtsov.ru.

2. Какие данные обрабатываются

  • имя;
  • адрес электронной почты;
  • содержание обращения или отзыва, если пользователь сообщает его добровольно;
  • выбранные дата и время встречи, организационные сведения о записи;
  • технические данные посещения: IP-адрес, сведения о браузере и устройстве, идентификаторы cookie, время посещения, адреса страниц и источники переходов;
  • события взаимодействия со страницами: переходы по ссылкам, клики, прокрутка и другие действия, фиксируемые подключённой веб-аналитикой.

Оператор не просит сообщать в открытых формах сведения о здоровье, подробности личной жизни клиентов или иную чувствительную информацию.

3. Цели и основания обработки

  • запись на диагностическую или рабочую встречу;
  • связь с пользователем и согласование условий работы;
  • заключение и исполнение договора оказания услуг;
  • получение обратной связи;
  • публикация отзыва только в согласованном с автором объёме;
  • анализ посещаемости, источников переходов и удобства сайта;
  • доставка страниц пользователю и обеспечение работы сайта.

Данные для записи и связи обрабатываются в объёме, необходимом для действий по запросу пользователя до заключения договора и его исполнения. Если для конкретной обработки требуется согласие, оно должно быть получено отдельно. Публикация этой политики и само посещение сайта не заменяют такого согласия.

4. Сервисы, участвующие в обработке

Для обращения и навигации используются Telegram и Telegram-бот, для самостоятельного выбора времени встречи — Cal.com, для получения отзывов — Яндекс Формы. Сайт размещён на GitHub Pages, для анализа посещений подключена Яндекс Метрика.

При записи через Cal.com обрабатываются имя, email, выбранное время и сведения, которые пользователь добавляет в форму. По опубликованной политике Cal.com сервис обрабатывает данные в США; отдельные поставщики сервиса могут обрабатывать их в других странах. Не указывайте в поле дополнительной информации сведения о здоровье, интимной жизни и содержание психологической работы. Для обсуждения способа записи можно связаться с оператором по email.

Сервисы могут обрабатывать данные по собственным правилам и в рамках предоставления услуг оператору. Переход пользователя во внешний сервис не освобождает оператора от обязанностей по защите персональных данных. Документы сервисов: Яндекс, Telegram, GitHub.

5. Веб-аналитика, cookie и локальное хранилище

На сайте используется Яндекс Метрика, счётчик № 111508227. В конфигурации включены Вебвизор, карта кликов и отслеживание переходов по ссылкам. Эти инструменты помогают оценивать источники посещений, работу страниц и действия посетителей.

Метрика может использовать cookie и технические идентификаторы браузера, сведения об устройстве, IP-адресе, посещённых страницах, источнике перехода, времени визита и событиях взаимодействия. Вебвизор позволяет воспроизводить действия посетителя на страницах сайта. Подробнее о работе с данными — в документации Яндекс Метрики.

В текущей версии сайта счётчик загружается при открытии страниц, на которых он подключён. Отдельный механизм предварительного выбора аналитики на сайте пока не реализован. Этот документ описывает действующую работу сервиса и не является согласием пользователя на обработку данных.

Браузер позволяет ограничивать или удалять cookie; блокировка сторонних запросов может ограничить загрузку аналитики. Удаление cookie не удаляет автоматически уже собранные сведения. По вопросам обработки и удаления данных можно обратиться к оператору по i@avkravtsov.ru.

Для запоминания закрытия предложения получить гайд сайт использует локальное хранилище браузера. Сохранённый выбор учитывается в течение 14 дней после закрытия окна либо 90 дней после перехода по его ссылке. Он не является согласием на аналитику. Хостинг также может обрабатывать технические журналы запросов для доставки и защиты сайта.

Текст отзыва может быть опубликован обезличенно. Имя, фотография, должность, место работы и иные данные, позволяющие определить автора, публикуются только после получения отдельного разрешения на распространение персональных данных. Согласие можно отозвать, направив письмо оператору.
